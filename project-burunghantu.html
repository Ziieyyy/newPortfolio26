System Challenge & Solution

Modernizing Local F&B Order Management

⚠️ The Challenge

Local independent eateries frequently rely on manual pen-and-paper ticket ordering or expensive third-party commission delivery portals that eat into profit margins. High peak-hour customer volumes cause lost chits, kitchen communication delays, and inventory tracking discrepancies.

✅ The Burung Hantu Solution

Built an autonomous, lightweight PHP and MySQL web commerce system allowing diners to browse categorized Western cuisine (steaks, pasta, burgers, beverages), customize portion preferences, manage orders in real-time, and automate kitchen order tickets with zero third-party commissions.

✦ Capabilities

Core System Architecture & Features

Reliable LAMP stack architecture built for high performance and fast checkout cycles.

🥩

Dynamic Menu Catalog

Categorized visual food catalog featuring high-resolution photography, allergen warnings, spice levels, and price listings.

🛒

Real-Time Shopping Cart

Interactive session-based basket with quantity steppers, special instruction notes for kitchen chefs, and automated subtotal calculation.

👨‍🍳

Kitchen Order Tracking

Relational MySQL database managing order states: Order Received → In The Kitchen → Ready For Serving → Completed.

👤

Customer Profile Hub

Secure customer portal with past order receipts, re-order favorites, and saved delivery/pickup contact details.

🔒

Secure SQL Handling

Sanitized PDO prepared statements preventing SQL injection vulnerabilities and ensuring reliable customer session encryption.

🚀

Cloud Edge Hosting

Containerized and deployed on Wasmer Edge for global availability, fast server-side responses, and low latency.
